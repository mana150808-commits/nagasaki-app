# Shunsai Nagaya の写真をここに入れてください

このフォルダ = `public/shops/shunsai-nagaya/`
（`src/data/shops.js` の `id: 'shunsai-nagaya'`, `photoBase: '/shops/shunsai-nagaya'` に対応）

## 入れるファイル（名前は完全一致で）
- `exterior.jpg` … お店の外観（ページ上部のバナー）
- `menu1.jpg` … Nagasaki Kuroge Wagyu Beef Tempura
- `menu2.jpg` … Yukou Shima-Aji Shabu-Shabu with Goto Udon Finish
- `menu3.jpg` … Pork Shoulder Roast Lemon Butter Steak on Hot Plate
- `menu4.jpg` … Shunsai Nagaya's Selected Sake Tasting Set

## メモ
- `.png` を使う場合は、ファイルを `.jpg` にリネームするか、
  `src/data/shops.js` の該当ファイル名を `'...png'` に変更。
- 置いたら `npm run dev` のページをリロードすると、プレースホルダー枠が写真に切り替わります。
- 写真が無い間は、テーマに合ったプレースホルダー枠が表示されます。
